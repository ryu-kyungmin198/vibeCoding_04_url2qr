URL2QR 사용 방법

  1. URL 입력: 화면 중앙의 입력창에 변환하고 싶은 웹사이트 주소를 입력하세요.
  2. 확인 클릭: 확인 버튼을 누르거나 키보드 Enter를 누르면 입력창이 하단으로 부드럽게 이동하고, 화면 정중앙에 고화질 QR코드가 생성됩니다.
  3. JPG 다운로드: 생성된 QR코드를 직접 클릭하거나 [JPG 다운로드] 버튼을 누르면 즉시 고해상도 JPG 파일이 다운로드됩니다.
  4. 연속 작업: 하단에 위치한 입력창에서 언제든 새로운 URL을 입력해 즉시 다른 QR코드를 만들 수 있습니다.
